# 한국통신학회 추계종합학술발표회 (예정)

**장소:** 강원도 홍천 소노캄 비발디파크  
**기간:** 2026년 11월 19일 ~ 2026년 11월 20일

## 활동 내용

**포스터 발표 예정**

- **연구 주제:** Q-learning 기반 선택적 정상 기준선 갱신을 통한 금속 산업 전력 이상탐지

### 연구 내용

- **연구 대상:** 금속 산업의 전력 시계열 데이터
- **연구 목표:** 정상 기준선의 선택적 갱신을 통한 전력 이상 탐지
- **접근 방법:** Q-learning을 활용한 정상 기준선 갱신 방법 연구
